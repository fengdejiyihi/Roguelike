# map_path_glow

- 名称：地图路径光晕
- 用途：替换主动可达路径的程序化 glow，沿 `source.next` 直接路径平铺或重复采样。
- 所属页面：地图界面（DreamQuest Map）
- 参考设计：`docs/ui/final-ui-source.png` 第 3「地图界面」的墨色虚线路径；原创材质，不裁切综合图。
- 尺寸：256×32
- 透明需求：RGBA，透明背景，可 tileable
- 优先级：P2
- 建议Prompt：原创 DreamQuest tileable map path glow strip, restrained teal-to-ink glow around a hand-drawn dashed route, soft feathered edges, no arrow, no text, seamless horizontal tile, transparent background.
